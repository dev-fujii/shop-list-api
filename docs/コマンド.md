# コマンド

手元で動かすときによく使うコマンド。パスワードはここに書かない（ユーザー シークレットに置く）。

## DB（Docker の PostgreSQL）

- コンテナー: `kakeibo-db`（`postgres:17`）
- つなぎ先: `localhost` の `5433`（コンテナーの中の 5432 につながる）
- ユーザー: `postgres`（既定のまま）
- DB 名: `kakeibo`

先に Docker Desktop を起動しておく。

```bash
# 動いているか確かめる（Exited なら止まっている）
docker ps -a --filter "name=kakeibo-db"

# 起動する
docker start kakeibo-db

# 止める
docker stop kakeibo-db

# 表の形を見る（例: Categories）
docker exec kakeibo-db psql -U postgres -d kakeibo -c "\d \"Categories\""

# 表の中身を見る（例: Categories）
docker exec kakeibo-db psql -U postgres -d kakeibo -c "select * from \"Categories\";"
```

## 接続文字列（ユーザー シークレット）

Visual Studio で、プロジェクトを右クリック →「ユーザー シークレットの管理」で `secrets.json` を開く。

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5433;Database=kakeibo;Username=postgres;Password=（ここにパスワード）"
  }
}
```

`dotnet user-secrets list` でも中身を見られるが、パスワードがそのまま表示されるので、画面を人に見せるときは注意する。

## マイグレーション（EF Core）

`ShopListApi/ShopListApi`（`.csproj` があるフォルダー）で実行する。

```bash
# マイグレーションを作る（名前は変えたことに合わせる。例: AddTransactions）
dotnet ef migrations add InitialCreate --output-dir Data/Migrations

# DB に当てる
dotnet ef database update

# 直前のマイグレーションを取り消す（まだ DB に当てていないとき）
dotnet ef migrations remove
```

## 起動

```bash
# http で起動（http://localhost:5247）
dotnet run --launch-profile http
```
